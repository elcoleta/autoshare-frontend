# AutoShare — Vue.js Frontend

Vue.js frontend for AutoShare, a full-stack car rental platform.

## Tech Stack
- Vue.js
- Vite
- Vue Router
- JWT Authentication

## Features
- Login, register, forgot/reset password
- Browse and filter cars
- Book cars with live availability
- Manage bookings and profile
- Internal messaging between users
- Admin dashboard

## Run

```bash
cd frontend
npm install
npm run dev
```

Open: `http://localhost:5173`

> Requires the backend API to be running. See [autoshare-api](https://github.com/elcoleta/autoshare-api)
